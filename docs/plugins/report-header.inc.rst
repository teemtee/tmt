The :tmt:story:`/spec/plans/report` step plugins present test results
or send them to external services.

Use the :ref:`/plugins/report/display` plugin to print results in the
terminal, the :ref:`/plugins/report/html` plugin to generate an HTML
report, or the :ref:`/plugins/report/junit` plugin to export test results into JUnit XML.
The :ref:`/plugins/report/polarion` and :ref:`/plugins/report/reportportal`
plugins send results to their respective services.

The default method is :ref:`display </plugins/report/display>`.
